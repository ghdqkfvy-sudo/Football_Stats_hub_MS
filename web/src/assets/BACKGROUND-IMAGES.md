## 바꾸는 법

파일만 덮어쓰면 됩니다. 코드는 손댈 필요가 없습니다.

- 가로가 긴 사진(1600×1067, 3:2)이 가장 잘 맞습니다. 비율이 달라도
  화면이 알아서 채우지만, 세로 사진은 위아래가 많이 잘립니다.
- 화면에서는 어둡게 깔리고 위에 팀 그라데이션이 덮여 **사진은 25% 정도만**
  보입니다. 너무 밝거나 글씨가 많은 사진은 피하는 편이 낫습니다.
- 이름과 확장자를 그대로 지켜 주세요. 바꾸려면
  `web/src/config/targets.ts` 의 import 도 같이 고쳐야 합니다.
- 덮어쓴 뒤 `push.bat` 을 실행하면 배포에 반영됩니다.

## 대한민국

`bg-kor.png`(배경)와 `crest-kor.png`(엠블럼)는 국기 규격(3:2, 태극 지름 =
가로/3, 4괘는 대각선 위)대로 직접 그린 그림입니다. 예전 배경 파일은 국기를
확대해 잘라 낸 사진이라 태극 문양이 오른쪽 위에 박혀 있었고, CSS 로는
가운데로 옮길 수 없었습니다 — 가운데에 놓이는 건 '이미지'지 '문양'이
아니기 때문입니다.
